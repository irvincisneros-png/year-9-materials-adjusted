# Year 9 - Materials Adjusted

Interactive HTML slide decks for the Year 9 Materials unit, organised by syllabus section.

Open the [deck index](index.html) to launch a presentation. Each deck is self-contained: imagery and interactive content are embedded in its HTML file. An internet connection is only needed for the optional Google-hosted Lexend font.
