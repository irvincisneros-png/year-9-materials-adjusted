🌍 REAL WORLD LINK

There is no automatic “greener” material

Compare a defined product system, not a label

The lower-impact option can change with the product, use pattern, transport, collection system and end-of-life route. Life-cycle evidence supports conditional comparisons.

THE PROBLEM

Crude-Oil Materials: Important Trade-Offs

Many conventional plastics use non-renewable fossil feedstocks
Extraction, production, transport, use and disposal can each contribute impacts
Many plastics can persist and fragment; rate depends on material and conditions
KEY CONCEPT

Life-Cycle Assessment Compares a Defined System

Stages: feedstock → manufacture → transport → use → end-of-life
Compare the same function, such as carrying 10 kg of groceries 50 times
Results depend on system boundary, data and assumptions—not one universal “best” material
ALTERNATIVES

Alternatives Are Material–Use Combinations

PLA: often bio-based; biodegradation depends on product and conditions
Recycled polymers: collection, processing and repeated recycling matter
Reusable materials: mass, washing, transport and actual reuse count matter

Compare the Same Job, Not the Label

Crude-Oil Plastic
Often lightweight with low material use per item
Consider feedstock, litter risk, collection and end-of-life
Compare against the same function and number of uses
Alternative (e.g. Glass)
Can be reused and recycled
Consider mass, production energy, washing and return distance
Actual reuse count and local recycling determine the comparison
CRITICAL THINKING

A Trade-Off Is a Question to Investigate

Cotton bag: check fibre production, washing, bag life and number of reuses
Aluminium container: check production energy, recycled content, collection and reuses
State the evidence, comparison baseline and uncertainty before recommending an option
TEACHER-LED PRACTICE

Build an evidence-aware recommendation

Choose a takeaway container for a school event. What must be true before you call it lower-impact?

1 · Define the job
How many meals? Hot or cold? Single event or repeat use?
2 · Compare options
State a baseline and at least two plausible alternatives.
3 · Set conditions
Collection, washing, transport, reuse count and disposal route.
4 · State uncertainty
What data or local information would you still need?
