IUPAC NAMING

What Is IUPAC Naming?

IUPAC = International Union of Pure and Applied Chemistry
Systematic IUPAC rules reduce ambiguity in chemical names
Name = prefix (carbon count) + suffix (compound type)

The Three Suffixes

Suffix
-ane
-ene
-ol
What it means
All single bonds (alkane)
Has a double bond (alkene)
Has an -OH group (alcohol)
BUILDING NAMES

Building an IUPAC Name

Step 1: Count the carbon atoms → choose the prefix
Step 2: Identify the bond type / group → choose the suffix
Step 3: Join them — e.g. prop- + -ane = propane
WORKED EXAMPLES

Worked Examples

methane = 1 C + all single bonds
ethene = 2 C + double bond
propan-1-ol = 3 C + OH on carbon 1
